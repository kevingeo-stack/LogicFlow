system_map.md# Architecture & System Map## 1. Class Hierarchy (Frontend OOP)- `AppController`: Orchestrates the interaction between routing and core modules.- `UIComponents`:  - `CodeEditorUI`: Wraps Monaco Editor instantiation (default language: Python).  - `CanvasUI`: Manages diagram interactions (zoom, pan).  - `DashboardUI`: Renders the history list and handles CRUD event listeners.- `CodeParser`: Abstract class handling AST/Regex code mapping.- `DiagramRenderer`: Wraps Mermaid.js/GoJS API for client-side rendering.- `ExportManager`: Injects Homework Template metadata and handles data conversion (PDF, DOCX, JPG).- `StorageManager`:   - `LocalDB`: Manages IndexedDB CRUD operations (Create, Read, Update, Delete for diagrams).  - `FirestoreSync`: Handles bi-directional sync with Firebase when online.## 2. Firestore Database Structure- Collection: `users`  - Document: `{user_uid}`    - Collection: `diagrams`      - Document: `{diagram_id}`        - Fields:           - `title` (string)          - `source_code` (string)          - `language` (string)          - `mermaid_markup` (string)          - `created_at` (timestamp)          - `updated_at` (timestamp)## 3. Routing (Client-Side)- `/` or `/dashboard` - History View (List of saved diagrams with Edit, Delete, and Export buttons).- `/editor/:id?` - Main workspace (If ID is passed, loads from history; if null, creates new).- `/settings` - Academic Profile setup (Name, Student ID, Class/Subject).
